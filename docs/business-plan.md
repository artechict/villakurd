## ۱. خلاصه اجرایی (Executive Summary)

**VillaKurd** اولین و تنها پلتفرم مارکت‌پلیس اختصاصی **رزرو ویلا در کردستان عراق** است. برخلاف رقبای عمومی (Divar، OLX، Airbnb)، ما **فقط روی نیچ ویلا** تمرکز داریم که باعث می‌شود:

1. **اعتماد بیشتر** - مسافران می‌دانند اینجا فقط ویلاهای واقعی و تاییدشده هستند
2. **تبدیل بهتر** - تجربه کاربری بهینه برای جستجوی ویلا (فیلترهای اختصاصی: استخر، حیاط، بارب큐، حیاط‌بازی)
3. **ارزش بالا** - میزبانان ویلا مشتری با ارزش بالاتر (LTV ۳-۵ برابر آپارتمان)
4. **رقابت کمتر** - هیچ پلتفرم اختصاصی ویلا در کردستان وجود ندارد

### ارزهای پیشنهادی
- **مشتری هدف:** خانواده‌های عراقی/کردستانی، خارجی‌های مقیم، توریست‌های منطقه
- **ارزش پیشنهادی منحصر به فرد:** "ویلاهای کردستان، یک کلیک دورتر - با اطمینان کیفیت و پرداخت امن"
- **مدل درآمدی:** هایبرید (کمیسیون ۱۲٪ + اشتراک $۲۹/ماه + خدمات جانبی)

## ۴. محصول و ویژگی‌ها (Product & Features)

### ۴.۱ MVP (Minimum Viable Product) - ماه ۱-۳

#### برای مسافر (Guest)
- [ ] جستجوی ویلا با فیلترها (موقعیت، تاریخ، مهمان، امکانات، قیمه)
- [ ] صفحه جزئیات ویلا: گالری عکس، نقشه، امکانات، قوانین، نظرات
- [ ] رزرو آنی / درخواست رزرو (بازه ۲۴ ساعته تایید میزبان)
- [ ] پرداخت آنلاین (AsiaHawala, Qi Card, ZainCash) + Escrow
- [ ] مدیریت رزروها: مشاهده، لغو، تغییر تاریخ، رسید
- [ ] نظرات و امتیازدهی پس از اقامت
- [ ] پروفایل: اطلاعات، اعتبارسنجی تلفن/ایمیل، desejo

#### برای میزبان (Host)
- [ ] ثبت‌نام و احراز هویت (KYC ساده: شناسه، مالکیت)
- [ ] افزودن ویلا: عکس‌ها، توضیحات، امکانات، تقویم، قیمه
- [ ] مدیریت تقویم: مسدود کردن تاریخ‌ها، قیمت‌گذاری فصل‌بندی
- [ ] مشاهده درخواست‌های رزرو: تایید/رد در ۲۴ ساعت
- [ ] داشبورد درآمد: رزروها، پэй‌اوت‌ها، کمیسیون‌ها
- [ ] پیام‌رسانی با مسافران
- [ ] پروفایل میزبان: تاییدشده، امتیاز، زمان پاسخ

#### برای ادمین (Admin)
- [ ] مدیریت کاربران: مسافران، میزبانان، تایید/معلق/مسدود
- [ ] مدیریت ویلاها: تایید، رد، ویرایش، ویژه‌سازی
- [ ] مدیریت رزروها: مشاهده، مدیتیشن اختلافات، بازپرداخت
- [ ] گزارش‌گیری: GMV، رزروها، کاربران، درآمد
- [ ] تنظیمات پلتفرم: کمیسیون، هزینه‌ها، قوانین

## ۶. مدل درآمدی و واحد اقتصاد (Unit Economics)

### ۶.۱ تفکیک درآمدی

```
برای هر رزرو میانگین $۲۵۰ (۲ شب × $۱۲۵/شب):

مسافر می‌پردازد:          $۲۵۰ (مبلغ رزرو) + $۱۵ (کارمزد درگاه) = $۲۶۵
│
├── پلتفرم (ما) می‌گیرد:    $۳۰ (۱۲٪ کمیسیون) + $۱۵ (کارمزد درگاه) = $۴۵
│   ├── هزینه درگاه:         -$۶.۲۵ (۲.۵٪)
│   ├── هزینه عملیاتی:       -$۵ (پشتیبانی، سرور، پرداخت میزبان)
│   └── سود خالص/رزرو:      ~$۳۳.۷۵
│
├── میزبان می‌گیرد:          $۲۲۰ (پایه) - $۳۰ (کمیسیون) = $۱۹۰
│   └── پéz-out:             هفتگی/ماهانه (انتخاب میزبان)
│
└── 정부의 مالیات:          مشمول میزبان (بر اساس قوانین عراق)
```
